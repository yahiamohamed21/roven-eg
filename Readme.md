# ROVEN Haute Parfumerie & Omnichannel Commerce Platform

نظام تجارة وإدارة متكامل لمجموعة عطور **ROVEN** الفاخرة مبني بأحدث تقنيات **ASP.NET Core (.NET 9.0)**، **Entity Framework Core 9.0.2**، و **SQL Server**.  
يجمع النظام بين متجر إلكتروني فاخر مخصص للعملاء (Boutique Storefront) مع فحص الطرود والدفع عند الاستلام (COD)، ولوحة تحكم متقدمة لإدارة دار العطور (Atelier & Back-Office ERP) مع تأمين كامل لعمليات البيع المتزامنة وتصدير الإكسيل وأرشفة SEO عالمية.

### 2. حل معضلة الـ Race Condition ومنع البيع الزائد (Zero Overselling)
تم حل مشكلة الطلبات المتزامنة (بين عميل المتجر الإلكتروني وموظف الكاونتر POS) على آخر قطعة مخزون عبر:
1. **الخصم الذري (Atomic SQL Update):**
   ```sql
   UPDATE [Products]
   SET [StockQuantity] = [StockQuantity] - @Quantity
   WHERE [Id] = @ProductId AND [StockQuantity] >= @Quantity;
   ```
2. **عزل المعاملات (Database Transactions):**
   استخدام `BeginTransactionAsync(IsolationLevel.ReadCommitted)` داخل خدمة مركزية موحدة `IOrderService` تضمن التراجع التلقائي (Rollback) في حال فشل أي بند.
3. **التحقق السيرفري المشترك:**
   كافة قنوات البيع (المتجر الإلكتروني، وإنشاء طلبات المبيعات الداخلية) تمر عبر نفس مسار الخدمة؛ مما جعل نسبة الخطأ أو البيع الزائد **0%**.

### 20. إعادة هيكلة مركز التحكم بالصفحة الرئيسية بنظام التبويبات والمزامنة الحية (Home Control Multi-Tab Suite & Instant Live Reflection)

     - **التبويب الأول (Hero Banners):** تحكم كامل في السلايدات الثلاثة (Slide 1, Slide 2, Slide 3) بكروت مستقلة تتيح تفعيل/تعطيل كل سلايد، وتعديل الشارة، العنوان الرئيسي، الوصف، نص وزر التوجيه.
