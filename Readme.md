# ROVEN Haute Parfumerie & Omnichannel Commerce Platform

نظام تجارة وإدارة متكامل لمجموعة عطور **ROVEN** الفاخرة مبني بأحدث تقنيات **ASP.NET Core (.NET 10.0)**، **Entity Framework Core 10.0.14**، و **SQL Server**، مع خط نشر آلي مستمر (**CI/CD Production Deployment**) ومزامنة سحابية فائقة السرعة للصور عبر **Cloudinary (WebP)**.  
يجمع النظام بين متجر إلكتروني استثنائي مخصص للعملاء (Boutique Storefront) مع فحص الطرود والدفع عند الاستلام (COD)، ولوحة تحكم متقدمة لإدارة دار العطور (Atelier & Back-Office ERP) مع تأمين كامل لعمليات البيع المتزامنة، وتصدير الإكسيل، وإدارة حية للبانرات والإعلانات، وأرشفة SEO عالمية تتصدر نتائج البحث.

**النطاق الحي للمشروع (Production Live):** [https://roven-eg.online](https://roven-eg.online)

### 2. حل معضلة الـ Race Condition ومنع البيع الزائد (Zero Overselling)
تم حل مشكلة الطلبات المتزامنة (بين عميل المتجر الإلكتروني وموظف الكاونتر POS) على آخر قطعة مخزون عبر:
1. **الخصم الذري (Atomic SQL Update):**
   ```sql
   UPDATE [Products]
   SET [StockQuantity] = [StockQuantity] - @Quantity
   WHERE [Id] = @ProductId AND [StockQuantity] >= @Quantity;
   ```
2. **عزل المعاملات (Database Transactions):**
   استخدام `BeginTransactionAsync(IsolationLevel.ReadCommitted)` داخل خدمة مركزية موحدة `IOrderService` تضمن التراجع التلقائي (Rollback) في حال فشل أي بند.
3. **التحقق السيرفري المشترك:**
   كافة قنوات البيع (المتجر الإلكتروني، وإنشاء طلبات المبيعات الداخلية) تمر عبر نفس مسار الخدمة؛ مما جعل نسبة الخطأ أو البيع الزائد **0%**.

- **شريط تصنيفات أفقي سريع التمرير (Mobile Horizontal Category Strip):** كبسولات تصنيفات تحت البحث مباشرة على الموبايل يتيح للعميل التبديل بلمسة واحدة بين (All, Extrait, Eau de Parfum, Rare Oud, Coffrets).

### 15. نظام إدارة المشغلين وتخصيص الصلاحيات (Role-Based Access Control)
- **ربط المشغلين بـ Identity و SQL Server (`Views/Users/Index.cshtml`):** استعراض حسابات المشغلين من جداول `AspNetUsers` و `AspNetRoles`، مع كروت مؤشرات أداء حية (إجمالي المشغلين، الحسابات النشطة، عدد المديرين، ومسؤولي المبيعات).
- **إنشاء وتعديل وتشفير المستخدمين:** تحديد الدور الوظيفي (`Administrator` أو `Employee`)، وحماية حساب المدير الشخصي من التعطيل أو الحذف العرضي.
- **مصفوفة الصلاحيات (Dashboard Permissions Matrix):** تغطية 4 قطاعات تشغيلية (الإدارة والتحليلات، المبيعات ونقاط البيع، الكتالوج والمستودعات، واجهة المتجر الإلكتروني) مع أزرار الضبط السريع (تحديد الكل، افتراضي السيلز، إلغاء التحديد).
- **ديناميكية القائمة الجانبية:** تخصيص السايدبار والداشبورد وفقاً لصلاحيات المستخدم المسجلة، وحجب الصفحات غير المصرح بها أمنياً بالتحويل التلقائي لصفحة `Access Denied`.

### 17. نظام إدارة البانرات الديناميكية للديسكتوب والموبايل (Dynamic Hero Banners Suite)
- **جدول `HeroBanners` في قاعدة البيانات:** دعم إضافة عدد غير محدود من البانرات الرئيسية مع تحكم كامل في:
  - صورة الديسكتوب (`DesktopImageUrl`) وصورة الموبايل المستقلة (`MobileImageUrl`).
  - العنوان الرئيسي، الوصف الفرعي، الشارة العلوية، نص الزر، ورابط التوجيه (`RedirectLink`).

- **عرض متجاوب ذكي عبر وسم `<picture>`:**
  ```html

  </picture>
  ```
  يضمن تحميل صورة خفيفة ومصممة خصيصاً لشاشات الهواتف الرأسية، وتحميل صورة عريضة فائقة الدقة لشاشات الكمبيوتر.

### 19. المزامنة السحابية التلقائية لصور المتجر (Cloudinary WebP Auto-Sync)
- **أتمتة المزامنة بالكامل في الخلفية (Zero-Click Sync):** إلغاء زر المزامنة اليدوي واستبداله بشارة حالة هادئة في لوحة التحكم (`☁️ مزامنة WebP التلقائية نشطة`).
- **المزامنة عند إقلاع السيرفر (Startup Background Sync):** دالة `DbInitializer.AutoSyncImagesToCloudinaryAsync` تفحص صور المنتجات والبانرات عند بدء تشغيل التطبيق وتحول أي صور محلية تلقائياً إلى صيغة WebP السحابية وتحدث قاعدة البيانات.
- **المزامنة الفورية عند الحفظ (On-Save Auto-Sync):** فحص ومزامنة الصور سحابياً تلقائياً بمجرد حفظ إعدادات الصفحة الرئيسية أو إضافة وتعديل أي بانر في `HomeControlController`.

### 21. تنقية وتطهير البيانات وإيقاف البذر التجريبي (Zero Fake Data Policy)

- **إيقاف البذر التلقائي المستقبلي:** تعديل `DbInitializer.cs` لإلغاء بذر أي منتجات أو عملاء تجريبيين عند إعادة تشغيل السيرفر، مع الحفاظ التام على حسابات المديرين والموظفين وصلاحياتهم.
- **توحيد أزرار جدول المخزون:** استبدال الأزرار المشوهة في جدول المخزون (`Inventory Management`) بأزرار ملكية موحدة للتوريد (`+ In`)، التسوية الجردية (`Adjust`)، وسجل الحركات (`History`).
